
# 🧪 Tests

This folder contains all automated tests for the project. The tests are organized into subfolders based on their type and purpose to ensure clarity and maintainability.

## 📁 Structure

- `unit/` – Contains unit tests that verify the functionality of individual components in isolation.

## ▶️ Running Tests

To run all tests:
`pytest tests/`

To run tests from a specific folder>:
`pytest tests/unit`

## ℹ️ Additional Information
For more detailed instructions, configurations, or specific guidelines, please refer to the README.md files within each subfolder.
