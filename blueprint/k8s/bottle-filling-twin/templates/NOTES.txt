🔧 Troubleshooting:

  If pods are not starting:
  1. Check events: kubectl get events -n {{ include "bottle-filling-twin.namespace" . }} --sort-by='.lastTimestamp'
  2. Check GPU availability: kubectl get nodes -l nvidia.com/gpu.present=true
  3. Check PVC binding: kubectl get pvc -n {{ include "bottle-filling-twin.namespace" . }}
  4. Check secrets: kubectl get secret -n {{ include "bottle-filling-twin.namespace" . }} {{ .Values.license.secretName }}

  If connection fails:
  1. Verify service endpoints: kubectl get endpoints -n {{ include "bottle-filling-twin.namespace" . }} {{ include "bottle-filling-twin.fullname" . }}
  {{- if .Values.envoy.enabled }}
  2. Check Envoy health: See health check section above
  {{- end }}
  3. Check firewall/security groups for ports {{ .Values.service.ports.signaling.port }} (TCP) and {{ .Values.service.ports.media.port }} (UDP)
